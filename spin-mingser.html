名瑟·SPIN销售话术练习

LED照明芯片销售场景 · 8道情景判断题

场景设定：你是厦门名瑟电子的销售工程师，代理杰华特电源管理芯片，主要客户是中山古镇的LED灯具厂。这家客户正在选用 AC/DC 电源方案用于球泡灯和筒灯，批量月需求 500K~1KK。下面 8 个场景，请你选出最佳的提问方式。
答题进度 1 / 8
第 1 题
【场景】你第一次拜访中山某LED球泡灯厂的张总，对方正在用别家芯片做5W球泡方案。第一步接触。
此刻最应该问的是哪类问题？ 开局阶段
[A] 你们的球泡灯现在能效做到多少？为什么这么低？P-难点
[B] 张总，方便介绍下您目前球泡灯的电源方案吗？用的是哪家的方案、批量多大？S-背景
[C] 用我们的方案，可以让您的整灯成本下降5%，您觉得有兴趣吗？N-效益
[D] 如果电源方案不稳定，会导致您客户投诉返修，这会带来多大损失？I-暗示
✅ 正确答案：BS（Situation 背景问题）—— 先了解客户现状、用谁家、批量多少、做什么产品。开局阶段不熟悉就问痛点，会让客户反感。

解析：SPIN开场为什么必须是 S？

原因 1：背景问题（S）建立信任。你刚进门就问"为什么这么低"等于指责对方选型差，关系直接破裂。

原因 2：S 是 P/I/N 的基础。不知道客户现状，痛点无从谈起。

原因 3：中山灯具厂老板很务实，开门见山聊方案、聊批量才是共同语言。

SPIN顺序口诀：先问"是什么"（S），再问"哪里难"（P），再问"会怎样"（I），最后问"想要啥"（N）。
第 2 题
【场景】张总说："我们现在用X家的线性方案，5W球泡月出货80万颗，主要走欧洲OEM订单。"
接下来最合适的提问是？ 了解阶段
[A] 我们的ErP线性方案能帮您通过最严的新能效法规！N-效益
[B] 如果您的方案过不了ErP认证，整个欧洲订单会全部停掉，您能承受吗？I-暗示
[C] 在用X家方案的过程中，有没有什么让您觉得不太顺手的地方？比如方案稳定性、性价比、技术支持？P-难点
[D] 您上一年的销售额是多少？公司有多少研发人员？S-背景
✅ 正确答案：CP（Problem 难点问题）—— 客户已经告诉你现状了（X家线性方案、欧洲OEM），现在该挖痛点。

解析：什么时候该从 S 切到 P？

关键信号：客户主动说出"在用X家方案、月出货80万颗、走欧洲"——这是 S 阶段信息已经收集充分的信号。

C 为什么对：用三个具体维度（稳定性、性价比、技术支持）引导客户说出难点，是经典的 P 问题。

A 为什么错：还没挖出痛点就上产品话术，是硬销。

D 为什么错：继续问 S 类问题，会让客户觉得你在走流程、不专业。

P 问题的标准句式："在用XX的过程中，有没有遇到XX的不便/困难/不满意？"
第 3 题
【场景】张总吐槽："X家技术支持响应太慢，改个方案要等两周；芯片能效也一般，整灯过ErP要折腾好几轮。"
客户说出了痛点，下一步最该问什么？ 放大阶段
[A] 您上一年的销售额是多少？公司有多少研发人员？S-背景
[B] 如果技术支持慢两周，遇上客户急单怎么办？会不会影响您按时交付？I-暗示
[C] 如果我们能当天响应技术支持，对您有什么价值？N-效益
[D] 您觉得技术支持响应多少小时比较合理？P-难点
✅ 正确答案：BI（Implication 暗示问题）—— 客户说出痛点后，要"放大"痛点的影响，让客户自己感受到紧迫性。

解析：I 问题的核心是"放大"不是"补刀"

I 的精髓：不评价、不推销，而是帮客户算账——"这个问题如果不解决，会带来什么连锁后果？"

B 为什么对：把"响应慢"和"急单/交付"挂上钩，让客户自己意识到这是一个会引发更大损失的问题。

C 为什么错：N 是让客户自己说出"我想要"——但 P 还没挖透，I 还没放大，不能急。

D 为什么错：还在 P 阶段打转，问题没深入。

I 问题的标准句式："如果/当XX，会导致什么？最终会影响到您的什么？"
第 4 题
【场景】张总叹了口气："去年因为ErP认证反复改版，耽误了两个月出货，损失了将近 200 万。"
此时最该问的是什么？ 引向价值
[A] 那您有没有考虑过换一家芯片厂商？P-难点
[B] 如果这200万订单不丢，您打算怎么用？N-效益
[C] 我们的杰华特ErP方案能帮您一次过认证，您要不要试试？N-效益（错）
[D] 如果有一种方案能让您一次过ErP认证，对您的客户满意度、复购率会带来什么变化？N-效益
✅ 正确答案：DN（Need-payoff 需求效益问题）—— 让客户自己描述"如果问题解决了，对我有什么价值"。

解析：N 问题的两个关键：客户说+具体场景

N 的精髓：让客户"自己说服自己"——价值由客户嘴巴说出来，比销售说 100 句都管用。

D 为什么对：1) 用了"如果有一种方案"——抽象问题；2) 让客户关联到具体业务（满意度、复购率）；3) 没推销自家产品。

B 为什么是陷阱：看起来是 N，但问的是"200万怎么花"，是私人问题，跳跃太大且不合适。

C 为什么错：这是销售硬推产品（"您要不要试试？"），不是 N 问题。N 是开放式的，让客户自己说价值。

N 问题的标准句式："如果（痛点被解决），对您的（具体业务指标）会有什么好处？"
第 5 题
【场景】张总点头说："是啊，方案能一次过ErP、又能稳定供货，我这边的客户投诉会少很多，老客户复购也稳了。"
客户已经"自我说服"了，下一步你最该做什么？ 临门一脚
[A] 继续问更多 S 问题，比如"您工厂有多大、有几条产线"。S-背景
[B] 继续挖痛点："那您还遇到其他什么问题吗？"P-难点
[C] 顺势提议："那我下次带我们杰华特应用工程师 + 样品过来，帮您做一份针对性的 ErP 方案？" 推进承诺
[D] 直接报底价："我们比X家便宜 10%，现在下单我给您申请优惠。"硬销
✅ 正确答案：C不是 SPIN 里的某一类，但这是 N 之后的"行动承诺（Advance）"—— 销售流程的自然推进。

解析：N 之后是"行动推进"，不是"继续提问"

SPIN 不是终点：SPIN 是挖掘需求的方法，挖到位后要顺势推向"具体下一步"。

C 为什么对：1) 调用技术资源（应用工程师），体现技术销售差异化；2) 带样品做方案，给客户一个低门槛的"试一下"动作；3) 不报价、不硬推。

D 为什么错：还没到报价时机。一旦报底价，客户就用价格筛选而不是价值筛选。

A/B 为什么错：客户已经自我说服了，再回到 S/P 就是"煮熟的鸭子又飞了"。

N 之后的标准动作：邀请具体下一步（送样、约见、做方案、上门测试），而不是继续提问或报价。
第 6 题
【场景】两周后你回访，张总说："你们上次送样的方案能效不错，但价格比X家贵了 5%。"
客户提出价格异议，最佳回应是？ 异议处理
[A] 立即降价 5% 留住客户。让步
[B] "一分价钱一分货，我们质量好。"争辩
[C] "张总，5% 的价差带来的综合成本差异，您之前算过吗？比如 ErP 通率、售后投诉、技术响应这些。"I-暗示
[D] "我回去跟领导申请，看能不能再让 2%。"拖延
✅ 正确答案：C用 I（暗示问题）把"价格贵 5%"放大到"全生命周期综合成本"——回到客户之前自己说过的痛点。

解析：价格异议的本质是"价值还没立住"

核心思维：客户说"贵"，不是真要你降价，是"价值认知不够"。要回到客户自己说过的痛点（ErP、投诉、技术响应）算总账。

C 为什么对：用客户自己提过的指标（ErP/投诉/响应）做对比，让客户自己算出 5% 价差换回的是几百万的损失避免。

A/B/D 为什么错：直接降价/争辩/拖延，都没解决"价值认知"问题，反而削弱了销售专业度。

价格异议的SPIN反制：用 I 把"采购成本"放大为"总拥有成本 TCO"，让客户自己重新算账。
第 7 题
【场景】张总点头："确实，去年光售后返修就花了 30 多万。"但随后说："不过我们老板对换供应商很谨慎，怕出品质问题。"
这是新冒出的风险类痛点，下一步最该问？ 挖风险痛点
[A] "我们是大厂，杰华特也是上市公司，绝对没问题。"打消
[B] "张总，您最担心的是哪个环节出问题？是品质异常、产能不足还是技术支持不到位？"P-难点
[C] "如果换供应商出问题，您觉得会有什么后果？"I-暗示
[D] "我们可以先送您 5K 颗样品做小批量验证。"行动建议
✅ 正确答案：BP（难点问题）—— 客户提出"担心风险"，先要把"风险"具体化，才能针对性打消。

解析：客户说"担心"时，最忌讳的就是立刻打消

"我们是大厂"为什么错：客户说担心，你的"绝对没问题"是空口承诺，反而加深不信任。

B 为什么对：把"担心"拆成三个具体场景（品质/产能/技术支持），让客户自己说出到底怕什么。一旦具体化，你才能精准打消。

C 为什么错：客户刚说"怕"，你接着说"会怎样"——会让客户更紧张，是反向 I。

D 为什么错：还没弄清楚具体风险，就直接上行动，错位。

当客户表达"担心/顾虑/犹豫"时，先 P（具体化）→ 再 I（放大不解决的后果）→ 再 N（解忧后的价值）→ 最后推进。
第 8 题
【场景】张总说："主要是怕品质异常，遇上急单时技术支持跟不上。"你回答后客户追问："那你能保证不出问题吗？"
客户要"保证"时，最佳回答策略是？ 建立信任
[A] "我保证100%没问题。"过度承诺
[B] "保证做不到，但我可以给您方案 ABC 三重保障..."理性分析
[C] "张总，没人敢100%保证。我能做的是：1) 我们的应用工程师驻点中山，2) 急单4小时响应，3) 杰华特原厂FAE直接对接。您看这三件事，对您够不够？"N-效益+承诺
[D] 避开话题："我们先看方案细节吧。"逃避
✅ 正确答案：C用 N 问题"对您够不够"——把"保证"转化为"具体保障条款"，让客户自己判断。

解析："保证"类问题的销售话术策略

客户要"保证"的心理：其实是想要"安全感"，但销售硬承诺 100% 反而会让客户觉得不专业。

C 为什么对：1) 先承认没人能 100% 保证（真诚）；2) 给出三个具体保障（驻点工程师/4 小时响应/原厂 FAE）；3) 反问"对您够不够"——这是高级 N 问题，让客户自己评估是否被满足。

A 为什么错：100% 承诺=以后出问题就违约，专业度归零。

B 为什么错："方案 ABC 三重保障"是销售自吹自擂，没让客户参与评估。

D 为什么错：逃避 = 没担当，关系立刻降温。

面对"保证"类问题，公式 = 承认现实 + 3 个具体保障 + 反问"对您够不够"（让客户自己说 YES）。
