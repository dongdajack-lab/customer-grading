场景 A · 经销商/代理商发展

说服区域暖通老板成为明珠加盟商

客户陈总，某三线城市暖通个体经营者，42岁，做了12年空调安装维修，带5人小团队
现状目前做"杂牌军"生意——什么品牌都接、什么单都干（家装分体机为主+偶尔小型工装），年营收约200-300万，毛利越来越薄。没有品牌授权，拿货价高，客户信任度低。
触发最近两年明显感觉生意难做：①大品牌直营下沉抢客 ②同行打价格战 ③几个老客户被"品牌店"撬走 ④招不到年轻人，团队老化。上周参加同城一个格力经销商的开业活动，心里很不是滋味。
顾虑担心加盟后不自由、压货压力大、投入回本慢、自己这把年纪折腾不动了。之前也了解过其他品牌的加盟政策，总觉得条件太苛刻。
目标向陈总推介江苏明珠区域加盟合作模式——品牌授权+产品直供+技术培训+营销支持+售后兜底，帮助他从"散兵游勇"升级为"正规军团"。
痛点毛利下滑/品牌缺失/客户流失/团队断层/转型焦虑/怕被割韭菜
销售：明珠渠道发展经理 客户：暖通个体户 陈总
场景 B · To B 工业销售

电子工厂车间恒温改造项目

客户李厂，某电子元器件厂厂长，52岁，技术出身
工厂3条SMT贴片产线+2条组装线，年产值约8000万
现状车间使用老式水冷空调+工业风扇降温。每年6-9月车间温度经常突破35℃，设备报警频发，良品率从98%降至93%。
触发今年接了某新能源汽车客户的订单，交期紧、良率要求严。上周因车间过热导致一批PCB板报废，直接损失12万。
目标向李厂推荐大金精密空调+松下全热交换新风组合方案，实现车间恒温26±1℃、洁净度达标，总预算约180万。
痛点良品率下降/设备故障/订单交期风险/工人安全
销售：明珠工程销售代表 客户：工厂厂长 李厂
场景 C · To C 家装零售

大平层中央空调+新风系统

客户张先生，35岁，科技公司高管，刚购200㎡大平层正在装修
家庭妻子（35岁·会计·有过敏性鼻炎）+ 儿子（1岁），父母偶尔来住
现状目前住120㎡老房子，用分体式挂机，噪音大、冷热不均。正在逛明珠连锁店对比方案，也在网上看美的、格力等品牌。
触发上周去朋友新家体验了中央空调+新风系统，老婆感受很好，说"这才是家的感觉"。但张先生算了下预算，比国产品牌贵了差不多5万。
目标推荐三菱电机中央空调+松下新风系统组合，200㎡全屋方案约12万（含安装）。国产方案约7-8万。

SPIN 提问设计工作单

根据所选场景，每个环节设计 2-3 个具体问题。注意：S→P→I→N 的顺序不能乱，上一环是下一环的铺垫。

场景A提示：经销商发展是"卖生意"，提问要围绕"不甘心→恐惧→算账→憧憬"的情感线。场景C提示：家装场景更情感化、生活化，多用"您和家人的感受""对孩子的影响"等视角，减少数据型追问。

SPIN 问题设计表 — 场景____（请填写 A、B 或 C）

S 现状问题
目的：了解客户现状，建立信任。不要急于推销。
例："陈总，您做暖通这行多少年了？现在团队几个人？主要做什么类型的业务？"
P 难点问题
目的：挖掘客户遇到的困难、不满、痛点。
例："这两年生意上最大的挑战是什么？有没有感觉客户越来越难留？"
I 影响问题
目的：让客户意识到问题的严重性和连锁后果。
例："如果这个趋势再持续两三年，对您的团队和生意会有什么影响？"
N 需求回报问题
目的：引导客户自己说出解决方案的价值，而不是你来说。
例："如果有一个品牌能帮您解决拿货价、客户信任、团队培养这些问题，对您意味着什么？"
角色扮演指引
🎯
角色：明珠销售代表
  • 先寒暄破冰（1句），不要上来就提问
  • 严格按照 S → P → I → N 的顺序提问
  • 每类问题至少问1个，重点发挥 P 和 I
  • Client回答后要回应/追问，不要像念稿
  • N 阶段让客户自己说出价值，忍住不要推销产品
  • 经销商场景特别提醒（陈总）：这是"卖生意给生意人"，不是卖产品。P 要挖的是他对现状的不甘心（"做了12年还在原地打转"）、对未来的恐惧（"再过3年被淘汰"）；I 要让他自己算账（不加盟的代价）；N 让他自己描绘"如果有了品牌背书会怎样"。切忌上来就讲政策条款，那是最后才谈的事。
  • To C 特别提醒：家装客户决策是感性的，用"您和家人"代替"贵公司"，用"感受/体验"代替"成本/效率"。重点打 P（家庭焦虑）和 I（不解决的后果），N 让客户描绘理想生活画面。
  • 全程时长控制在3分钟以内
🎭
角色：客户（陈总/李厂/张先生）
  • 通用：真实扮演一位理性、有预算压力的决策者
  • S 类问题：如实介绍现状
  • P 类问题：承认困难，但不说解决方案
  • I 类问题：表现出担忧、焦虑（但不是绝望）
  • N 类问题：开始主动思考"如果解决会怎样"
  • 不要主动提出"我要买你的空调"，等销售引导
  • 经销商场景特别提醒（陈总）：你是做了12年的老兵，见过太多"加盟被割韭菜"的同行，所以天然防备心重。S 阶段会如实说自己的生意情况（带点自嘲），P 阶段会吐苦水但不示弱，I 阶段开始真正焦虑，N 阶段才会松口问"你们具体怎么合作"。不要轻易表态"我要加盟"，等销售把你说服。
  • To C 特别提醒（张先生）：你是家庭决策者，妻子感受和小孩健康是核心焦虑，不是预算数字。当销售打情感牌时会被触动，当销售只谈参数时会不耐烦。
