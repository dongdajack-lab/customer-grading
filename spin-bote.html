郑州波特·SPIN销售话术练习

粮油加工与粮食仓储自动化场景 · 8道情景判断题

场景设定：你是郑州波特控制技术有限公司的销售工程师。公司 2009 年成立，国家级高新技术企业、2025 年国家级科技型中小企业，专做粮油行业的自动化控制系统——面粉厂 PLC 系统、粉率系统、一卡通无人值守收粮系统、生产管理系统、在线装车系统。客户是面粉与米业集团、粮食储备库、饲料厂、食品厂；2025 年中标项目金额 3497.68 万元，客户分布全国。下面 8 个场景，请你选出最佳的做法。
答题进度 1 / 8
第 1 题
【场景】你第一次进厂，见到面粉集团分管生产的赵总。他 15 分钟后要开会，坐到你对面的第一句话是：「你们公司我知道，做面粉厂控制的。我们这条线 PLC 是设计院带过来的，用着还行。」
此刻最应该问的是哪类问题？开局阶段
[A] 你们的出粉率才 75%，比行业标杆低 2 个点，一年亏多少您算过吗？
[B] 赵总，咱们这条线日处理小麦大概多少吨？出粉率现在控制在什么水平？
[C] 我们是国家级高新技术企业，服务过多个面粉项目，我先花几分钟给您介绍下公司。
[D] 您现在的 PLC 系统是哪家做的？当时投了多少钱？
✅ 正确答案：BS（Situation 背景问题）—— 先了解客户现状：日处理量、当前出粉率。这两个数客户张口就能答，又不涉及机密。

解析：SPIN 的开场为什么必须是 S？

原因 1：A 项看着「专业」，其实是当众给赵总判分。他干了二十年面粉，第一句就被告知「你差两个点」，后面的话他一句都听不进去。

原因 2：D 项也算背景问题，但踩了两个雷——打听竞争对手、打听价格。第一次见面就问这些，客户会把你归类为「来摸底的」，而不是「来解决问题的」。

原因 3：C 项是自嗨式开场。而且在面粉行业，报别家的项目名字，客户第一反应是「你是不是也拿我去当案例」。

SPIN 顺序口诀：先问「是什么」（S），再问「哪里难」（P），再问「会怎样」（I），最后问「想要啥」（N）。开场只做一件事——把事实问清楚。
第 2 题
【场景】赵总回答：「日处理小麦 3000 吨，出粉率 75% 上下。这数儿我还得看报表，车间报上来的，一天一报。」
接下来最合适的一问是？了解阶段
[A] 75% 太低了赵总，行业标杆都 77% 了。
[B] 我们的粉率系统能实时采集，比人工准得多，我给您讲讲原理？
[C] 手抄、第二天才汇总——那有没有出现过这种情况：某个班粉率掉下来了，等您看到报表，那批麦子已经磨完了？
[D] 那你们现在的吨粉能耗指标是多少？
✅ 正确答案：CP（Problem 难点问题）—— 客户已经给了你现状（3000 吨、75%、一天一报），现在该把话题从「事实」引向「不满」。

解析：什么时候从 S 切到 P？

关键信号：客户主动说出了「手抄、下班交、第二天早上汇总」——这是 S 阶段信息已经充分的信号，也是他亲手递给你的入口。

C 为什么对：不下结论、不评价，只请他回忆一个具体场景。客户一旦讲出「有过，上个月那批 300 吨……」，痛点就从「你猜的」变成「他自己说的」。

A 为什么错：指出客户比标杆低 2 个点 = 当众打脸，数字没错，时机全错。

B 为什么错：痛点还没浮出水面就讲原理，是自说自话；D 项则是继续问 S，节奏一步没往前。

难点问题的公式 = 不评价 + 给场景 + 请他回忆。例：「有没有出现过……等您看到报表，那批麦子已经磨完了？」
第 3 题
【场景】赵总承认：「有过。上个月一批麦子水分偏高，车间没调参数，等我看报表的时候，那 300 吨麦子已经磨完了，粉率掉了 1.2 个点。」
此刻最该说（问）的是？放大阶段
[A] 所以您看，上一套在线监测系统还是很有必要的。
[B] 我们系统能提前 2 小时预警，这种事绝对不会再发生。
[C] 这种偏差在面粉厂其实很普遍，您不用太自责。
[D] 300 吨、1.2 个点就是 3.6 吨面粉，按现在的行情这一批少赚一万多——像这样的月份，一年有几次？
✅ 正确答案：DI（Implication 暗示问题）—— 用客户自己的数字算成钱，再问频次，把一次意外放大成常态。

解析：痛点放大不是「说得多严重」，是「算得多清楚」

D 为什么对：300 吨 × 1.2% = 3.6 吨面粉，按行情一万多块；再问「一年几次」——客户自己得出「一年几十万」。这个结论是他算出来的，不会反驳自己。

A 为什么错：客户刚露出伤口，你立刻说「所以你要买」。他把这当成趁火打劫，前面挖的痛点全废。

B 为什么错：在生产口，「绝对不会」这四个字最不值钱，赵总听到的潜台词是「你不懂现场」。

C 为什么错：安慰等于替客户宣布「这事无所谓」。他一放松，你的机会就没了。

暗示问题公式 = 客户的原话数字 × 单位价格 × 一年频次 = 他必须面对的损失。
第 4 题
【场景】赵总顺着你的话算了算：「一年总有个七八回，加起来几十万跑不掉。」他停了停，又说：「唉，老板今年给我们生产口下了 300 万的降本指标，我这头发都要掉光了。」
此刻最该接的一句是？升级阶段
[A] 粉率每稳 0.1 个点，一天就是 3 吨面粉，一个月二十五万上下——老板要的那 300 万，可能就藏在 1 个点里。
[B] 所以赵总，您更需要上我们的系统，帮老板把这 300 万省出来。
[C] 我们有个客户上了系统之后，一年光粉率这块就多赚了 500 万。
[D] 降本 300 万压力确实大，生产这块最难做，您辛苦了。
✅ 正确答案：AI→N 的桥梁 —— 把客户的痛点，换算成他老板考核他的那个数字。

解析：为什么是「换算成他老板的 KPI」？

A 为什么对：3000 吨 × 0.1% = 3 吨/天，一天一万出头，一个月二十五万——一年就是 300 万量级。你不是在卖系统，你是在帮他把老板的指标接住。

B 为什么错：「所以您更需要」是典型的销售腔——你替他做了决定。这句话一说，前面挖的痛点全部作废。

C 为什么错：讲别人的账，客户心里自动打折。真正有说服力的账，是用他自己刚才报的数字算出来的。

D 为什么错：共情到此为止。你从「帮他想办法的人」，变成了「听他倒苦水的人」。

价值问题的公式 = 客户的业务指标 × 微小改善 × 他的考核周期 = 他老板要的那个数。
第 5 题
【场景】赵总拿笔算了一遍，抬头问你：「你等等，这个算法你再给我说一遍……算了。小朱，这套东西多少钱？什么时候能上？」
客户主动问价、问周期，此刻最该做的是？推进阶段
[A] 大概六十万，您要是这个月定，我给您申请个九折。
[B] 赵总您稍等，我回去做一份完整的方案，做好发您邮箱。
[C] 钱我明天给您一个实在的数。但报价之前，我想先借您最近三个月的粉率报表，按您的麦子、您的设备跑一次数据对标，算出到底能捞回多少——这周五方便吗？
[D] 我们可以先免费给您装一套试用，用得好再说钱。
✅ 正确答案：CN（Need-payoff 效益问题）+ 收口 —— 不拒绝报价，但把报价变成「用他的数字算出来的账」。

解析：客户主动谈钱时，为什么恰恰不该报价？

C 为什么对：你只推后一步，拿到他的三个月报表。有了它，你就从供应商变成他的「数据合伙人」，报价也不再是一个可以被砍的数字——而且客户必须付出一次投入，承诺才真实。

A 为什么错：报价 + 折扣 = 告诉他你的价格有水分。以后每一次见面，都要再让一次。

B 为什么错：没有时间、没有动作、没有客户承诺的方案，大概率在邮箱里睡觉。

D 为什么错：在生产口，「免费」约等于「不担责、不负责」——你把自己最值钱的东西换成了最不值钱的姿态。

收口公式 = 具体动作 + 具体时间 + 客户必须贡献的一样东西（他的数据/他的目标）。
第 6 题
【场景】这次客户换成了省级储备粮直属库的仓储科钱主任，项目要走公开招标。他在技术交流会现场对你说：「你们材料我都看了。你先报个价吧，我心里有个数。这种事啊，好不好我说了不算，审计说了算。」
最佳应对是哪一句？特殊场景 · 招投标
[A] 钱主任，我们价格有优势，肯定比别家低。
[B] 报价我一定给。不过在报之前，我想先请教一件事：这次升级，上级考核验收主要看哪几个指标？
[C] 我们做过中储粮系统的项目，经验很足，您放心。
[D] 钱主任，那这次改造的预算大概是什么规模？
✅ 正确答案：B体制内客户的第一入口 —— 不是价格，是「怎么验收、怎么过审计」。

解析：跟体制内客户，第一句话决定你被归到哪一类

B 为什么对：他刚说了「审计说了算」，你顺着问「验收看什么指标」——这是他的语言，也是整个项目的方向盘。

A 为什么错：在体制内，「便宜」往往等于「风险高、以后说不清」。你第一句就把自己送进了价格笼子。

C 为什么错：想用项目背书，反而触发纪律警觉。而且还没搞清他要什么，自证没有意义。

D 为什么错：问预算不算错，但属于敏感项，现场不可能有答案。问早了只会显得不懂规矩。

对体制内客户：先问标准（验收），再问现状（流程），最后才谈产品与价格。
第 7 题
【场景】一位三年前做过电气安装的老客户来电，设备科长说：「你们那个系统，我们想加点东西。」上次合作验收评价不错，后续也没再联系过。
最该做的是？特殊场景 · 老客户复购
[A] 太好了，您要加什么功能？我直接给您报个价。
[B] 三年前的线该整体换新了，我给您做一套全面改造方案。
[C] 我先把三年前的合同调出来看看，再跟您对。
[D] 加什么功能先放一放。我更想知道：这三年系统用下来，哪几个环节您觉得还是靠人在扛？当初没做的功能，现在为什么想做了？
✅ 正确答案：D复购不是「接单」，是把「想加点东西」还原成真实的痛点。

解析：老客户是最好挖的痛点矿，前提是你别急着接单

D 为什么对：「想加点东西」只是客户对问题的模糊表达。问「哪个环节还在靠人扛」，你才能知道这三年他到底忍了什么——这类增量需求，往往比新客户的主项目更容易成。

A 为什么错：接单思维。你说报就报，报完他还要比价，你又回到了价格战里。

B 为什么错：把技改直接升格为整体改造，客户第一反应是「你又想让我大出血」，当场缩回去。

C 为什么错：翻合同属于事务性动作，不产生任何信息。客户打这个电话，是有话想说的。

老客户复购公式 = 先问「这几年哪里还靠人扛」，再谈加什么；老客户最大的价值是转介绍，而转介绍只在「你帮他把事办成」之后发生。
第 8 题
【场景】六轮谈下来，客户松了口：「那你先做个方案吧。」
收口时最该做的是什么？收口阶段
[A] 方案我做没问题。不过方案里最关键的一个数——目标出粉率——得您来定；下周三我带着方案来，跟您和技术科一起过一遍，行吗？
[B] 好的，我尽快做好发您邮箱。
[C] 那您对价格的心理预期大概是多少？
[D] 方案做完我先发您，您觉得可以咱们再约。
✅ 正确答案：A收口 = 具体动作 + 具体人 + 具体时间 + 客户必须贡献一个东西。

解析：收口收的不是合同，是「下一步动作」

A 为什么对：你请客户定「目标出粉率」——他一旦给了这个数，方案就变成了他的方案；而约定了带方案上门的时间，见面就是必然发生的。

B 为什么错：没有时间、没有对象、没有承诺的「尽快」，等于把节奏交出去。客户的邮箱里，躺着几十份这样的方案。

C 为什么错：方案阶段谈价格，会让客户提前进入砍价模式，你的方案价值在他眼里只是一个报价单。

D 为什么错：「您觉得可以咱们再约」——你把下一次见面变成了客户的义务，而不是你的责任。

收口公式 = 具体动作 + 具体时间 + 客户必须贡献的一样东西（他的数字、他的目标、他的决策人）。欠了客户「一个数」的方案，自然要见面交。
