第 1 步 · 搜索关键词Search Keywords

① 产品关键词（搜到"用这类设备的人"）

AMR / Autonomous Mobile Robot AGV / Automated Guided Vehicle Pallet Mover / Automated Pallet Jack Forklift Automation / Automated Forklift Reach Truck / Stacker Automation Warehouse Robot / Intralogistics Robot

② 应用场景关键词（搜到"有这个痛点的行业"）

Cold Storage / Cold Chain Warehouse Fulfillment Center / E-commerce Warehouse 3PL / Third-Party Logistics Manufacturing / Factory Internal Logistics Cross-docking / Distribution Center

③ 成交客户网站关键词（搜到"相似画像的客户"）

把已成交客户（欧洲冷链仓、东南亚电商履约中心、海外超市配送仓）官网上的用词扒下来，用同类词去搜——成交客户的"自我描述"，就是下一批客户的"搜索密码"。

warehouse automation project internal logistics solution pallet transfer / pallet handling labor shortage solution

④ 组合搜索技巧

  • 关键词 + 职位：如 "Warehouse Operations Manager" + AMR —— 直接搜出"管仓库的人"
  • 关键词 + 地区：欧洲（冷链）、东南亚（电商履约）、中东（新物流枢纽）—— 按海豚之星已进入的 20+ 国家排优先级
  • 竞品关键词：搜竞品品牌的关注者/客户评价，竞品教育过的客户最容易转化

第 2 步 · 进入主页分析与判断Profile Analysis

判断维度海豚之星客户的判断标准
① 公司类型 直接客户：3PL/物流服务商、电商履约中心、冷链仓储运营商、制造企业（食品/家电/3C/汽车零部件/新能源——厂内物流搬运）
渠道客户：叉车/物料搬运设备（MHE）经销商——海豚之星有渠道伙伴体系，经销商是规模化入口
生态客户：仓储自动化集成商——项目带入型合作
排除对象：同类 AMR 厂商——不开发，转为竞情分析对象
② 公司规模 员工人数：2-10 小规模｜10-20 中小型｜20-50 中型｜50-100 大型｜100-500 超大型。
重点看仓库数量与面积（主页/动态/官网判断）；大型连锁（如超市配送中心）决策链长，要顺着组织架构找到总部供应链部门
③ 业务范围 有没有仓库/工厂？现在怎么搬运？——还在用人工叉车 = 最好的替换目标；已上过输送线的，找"改造扩建"机会；已用竞品 AGV 的，记入竞情库
④ 市场方向 动态里是否有：新开仓库/新工厂、业务扩张、关注 labor shortage / automation / efficiency 话题——有 = 需求窗口已开
⑤ 动态发布 旺季招聘叉车司机/仓管 = 人力成本痛点信号 = 自动化切入时机；招聘 "Automation Manager / Continuous Improvement" = 已有自动化预算，重点跟进
判断口诀：招聘信息比广告真实——一个仓库在疯狂招叉车司机，说明它最需要不招人的叉车。

第 3 步 · 决策人及职位Decision Makers

仓库 / 物流 / 制造类客户

Owner / CEO / General Manager（中小仓库一把手） COO / Operations Director Supply Chain Director / Manager Logistics / Warehouse Operations Manager Plant / Factory Manager Automation / Innovation Manager Procurement / Purchasing Manager Project Manager

渠道类客户（叉车/MHE 经销商）

Owner / General Manager Business Development Manager

找人顺序（跟找邮箱一样重要）

  • 先用"职位 + 地区 + 行业"搜人 → 再从人进入公司主页——真人比公司主页容易建立联系
  • 对标决策链口诀：使用者（仓库主管，提需求）→ 拍板者（COO/老板，批预算）→ 采购者（Procurement，走流程），三条线都要有人
  • 发好友申请前先看对方"近期动态"，最近发过仓储/扩张内容的，通过率最高

第 4 步 · 如何建立联系Make Contact

  1. 发好友申请前，先写好针对性模板——不写产品介绍，写对方痛点场景；消息里带一个真实案例钩子
  2. 关注客户公司主页 + 决策人个人，通过 Find E-mail 等插件找到邮箱
  3. 进入公司官网进一步找联系方式：邮箱、电话、WhatsApp——领英 + 邮件 + WhatsApp 三通道立体触达（欧洲客户邮件正式沟通，东南亚/中东客户 WhatsApp 直接高效）
  4. 配合跟进节奏：领英破冰 → 发同类场景案例视频（如超市配送仓 31 台机器人项目）→ 约线上 Demo（远程看真机运行）→ 邀约展会见面（LogiMAT / CeMAT / Modex 现场看设备）
好友申请模板（海豚之星版）：
"Hi Mark, saw your post about expanding to the new fulfillment center. Many warehouse managers we work with in [region] struggle with seasonal hiring forklift drivers — we helped a supermarket distribution center automate pallet transfer with 31 AMRs. Would love to connect and share how it works."
中译：看到您新履约中心开业的消息。我们服务的很多 [地区] 仓库经理都被旺季招叉车司机难住了——我们帮一个超市配送仓用 31 台 AMR 解决了托盘搬运。希望与您建立联系，聊聊具体怎么做。

第 5 步 · 打造专业领英页面Professional Profile

① 个人主页 Intro

  • Headline 职业头衔："AiTEN AMR Robots | Warehouse Automation | No Infrastructure Required, Deploy in 1 Day | 800+ Customers in 20+ Countries"——头衔就是搜索关键词，让客户搜 AMR 时搜到你
  • Profile URL：用产品行业关键词自定义（如 linkedin.com/in/xxx-amr-warehouse-automation），并填写公司网址
  • Summary 自我简介五要素：你是谁（AiTEN 海外销售）+ 提供什么（搬运/堆垛/装卸/移载全场景物流机器人 + 智慧调度平台）+ 优势（第三代 SLAM 导航，无需磁条二维码，到货即部署；112+ 专利；国家级专精特新小巨人）+ 给客户带来什么（省人、防损、快回本，配数据）+ 官网/邮箱联系方式——搭配案例视频作品展示实力

② Background 经历

  • Work experience / Education 尽量完善——信息越详细，客户心里的可信度越高；每段经历配照片和公司主页链接

③ Skills 技能专长

AMRAGVWarehouse AutomationIntralogisticsMaterial HandlingForklift AutomationSupply ChainLogistics 4.0
  • 系统推荐 + 核心产品行业关键词组合——Skills 直接影响领英搜索排名

④ Accomplishments 个人成就

  • 海外项目案例：欧洲冷链仓库、东南亚电商履约中心、海外超市配送仓 31 台项目
  • 展会经历：LogiMAT / CeMAT / Modex 现场照片
  • 客户验收现场、发货柜照片——客户翻你主页时，看到的是"这家公司海外案例很多"

⑤ 定期发布（运营策划图片视频，销售总监给思路和文案）

  • 一周 2 次：新品发布、整柜发货、海外项目现场、客户验收、展会预告
  • 每条动态 = 一次自我广告；持续输出，客户主动找上门
五步法的价值：老销售的"人脉感觉" → 变成新销售的"标准动作"。
关键词搜得出、主页看得懂、决策人找得到、联系搭得上、页面信得过——新员工入职第一周就能照着开发海外线索，这就是流程化 + 工具化的力量。
